All systems and architectures

Windows

Your system

Windows 10 / 11, 64-bit

Installer · x64.exe setup Portable · x64Portable .exe, no installation

The current Windows installers are unsigned. The project is applying to SignPath Foundation for code signing. If SmartScreen appears, choose “Run anyway”. Windows 11 on ARM runs the x64 build through built-in emulation.

macOS

Your system

Apple silicon (M series) and Intel

Apple silicon · arm64.dmg disk image Intel · x64.dmg disk image Apple silicon · arm64.zip archive Intel · x64.zip archive

The app is not signed by Apple. If macOS says it is damaged or can’t be opened, move it to Applications and run xattr -cr /Applications/WrongNotebook.app and codesign --force --deep --sign - /Applications/WrongNotebook.app in Terminal, then open it. Not sure which chip you have? Check “About This Mac”.

Full deployment guide

Want new features early? Download a preview build (pre-release) from GitHub Releases. Fresh installs have no default account: the desktop and standalone Android apps open the admin setup page on first launch, fnOS asks for the admin email and password in the install wizard, and Docker and npm print a one-time setup link in the startup log.
