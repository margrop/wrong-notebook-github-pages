反馈问题或建议
使用这个项目，需要付费吗？

项目基于 MIT 许可证免费开源，提供源码、Docker 镜像、npm 包和各平台安装包供自行部署。AI 识题、生成讲解等功能需要配置自己的 AI 服务，调用费用由对应服务商收取，也可以直接选择 MiniMax、智谱 GLM、DeepSeek、Kimi 官方渠道，或接入兼容 OpenAI、Anthropic 接口的服务。

可以先试用一下吗？

可以。打开 在线演示站，使用账号 demo@localhost、密码 demo123456 登录。演示站为共享账号，数据对所有访客可见，请勿录入个人信息；正式使用建议部署自己的实例。

支持哪些系统和设备？

服务端可以运行在 Windows、macOS、Linux 桌面版，飞牛OS NAS，以及任何支持 Docker 或 Node.js 的服务器上。部署后，手机、平板和电脑都能通过浏览器使用。桌面版默认只允许本机访问，飞牛OS、npm 和 Docker 部署可在局域网内访问。

适合哪些年级和学科？

创建错题本时可以选择小学、初中或高中学段，以及对应学科。系统按学段、学科组织知识点，支持自定义标签；AI 可辅助识别知识点和难度。

可以在手机上用吗？

可以。应用支持手机、平板和电脑浏览器，并提供 PWA 支持。在 iPhone / iPad 的 Safari 分享菜单，或 Android Chrome 菜单中选择「添加到主屏幕」，即可像 App 一样打开。

数据存在哪里？可以完全离线吗？

题目和作答记录保存在你部署环境的 SQLite 数据库中，AI 配置也保存在自己的部署环境。AI 识别、解答和生成等功能会向所配置的服务发送相关内容，需要该服务可访问；PWA 不等于完整离线运行。

GitHub Pages 能直接运行错题本吗？

这个官网可以通过 GitHub Pages 托管。错题本应用本身包含登录、数据库和 AI 接口，需要运行服务端：可以直接安装桌面版或飞牛OS 安装包，也可以用 npm 或 Docker 部署到电脑、NAS 或服务器。想先看看效果，可以使用在线演示站。

和上游 wrong-notebook 有什么关系？

本项目基于 wttwins/wrong-notebook 扩展，增加了中英文 SVG 动画讲解、掌握情况跟踪、可配置判重、试卷作答回填、国产大模型官方渠道、中英文界面和全平台安装包等功能。感谢上游作者的工作。完整功能与差异请查看项目 README。
