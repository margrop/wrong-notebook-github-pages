macOS

你的系统

Apple 芯片（M 系列）与 Intel 芯片

Apple 芯片 · arm64.dmg 安装镜像 Intel 芯片 · x64.dmg 安装镜像 Apple 芯片 · arm64.zip 压缩包 Intel 芯片 · x64.zip 压缩包

应用未经 Apple 签名，提示「已损坏」或无法打开时，拖入「应用程序」后在终端执行 xattr -cr /Applications/WrongNotebook.app 和 codesign --force --deep --sign - /Applications/WrongNotebook.app，再打开即可。不确定芯片型号？可在「关于本机」中查看。

iPhone / iPad

用 Safari 打开自己部署的服务器（或在线演示站），在分享菜单中选择「添加到主屏幕」，即可像 App 一样打开。

服务器 · NAS · 已有 Node.js 环境

Docker 镜像支持 amd64 / arm64；npm 需要 Node.js 22.15+

Docker
docker run -d --name wrong-notebook -p 3000:3000 \
  -e NEXTAUTH_SECRET="$(openssl rand -hex 32)" \
  -v "$(pwd)/data:/app/data" -v "$(pwd)/config:/app/config" \
  ghcr.io/margrop/wrong-notebook:latest
npm
npm install -g wrong-notebook
wrong-notebook --port 3000
离线 npm 包.tgz，可用 npm install -g 安装
